AI CODE CHECKER - HOW TO RUN THE SERVER
=======================================

What you need
-------------
- Python 3.10 or newer (check with: python --version)
- The project folder, containing:
    app.py
    templates/index.html
- A free Gemini API key (Step 6). Each person should use their OWN key.
- Windows PowerShell (Mac/Linux alternatives are shown where they differ)


Step 1 - Open the project folder in PowerShell
----------------------------------------------
cd path\to\ai-code-checker


Step 2 - Create a virtual environment (first time only)
-------------------------------------------------------
python -m venv venv


Step 3 - Allow scripts for this PowerShell window (Windows only)
----------------------------------------------------------------
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

(This only lasts for the current window. Skip it if activation in Step 4 already works.)


Step 4 - Activate the virtual environment
-----------------------------------------
Windows:    venv\Scripts\Activate.ps1 or venv/bin/activate
Mac/Linux:  source venv/bin/activate

You should now see (venv) at the start of your prompt.
You must do this every time you open a new terminal window.


Step 5 - Install Flask (first time only)
----------------------------------------
pip install flask

(Nothing else is needed. The google-genai package is NOT required.)


Step 6 - Get your own free Gemini API key
-----------------------------------------
1. Go to https://aistudio.google.com/apikey
2. Click "Create API key".
3. Copy the key. It starts with "AQ." - that is normal.

Never paste your API key into app.py, a chat, a screenshot, or GitHub.


Step 7 - Set the key in the SAME terminal window
------------------------------------------------
Windows:    $env:GEMINI_API_KEY="PASTE_YOUR_KEY_HERE"
Mac/Linux:  export GEMINI_API_KEY="PASTE_YOUR_KEY_HERE"

- Paste only the key itself. No extra letters at the start, no spaces.
- This lasts only for this window. Set it again if you open a new terminal.
- Check it worked (Windows): echo $env:GEMINI_API_KEY


Step 8 - Start the server
-------------------------
python app.py

Leave this window open. Stop the server any time with Ctrl+C.


Step 9 - Open the app
----------------------
In your browser go to:  http://127.0.0.1:5000

Paste some code and click "Review Code".


Next time you run it
--------------------
You only need Steps 1, 3, 4, 7, 8 and 9.
